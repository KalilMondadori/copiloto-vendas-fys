# 🥤 Assessor de Vendas FYS — Copiloto com IA para Atendimento ao Cliente

## 📌 O que é este projeto

Um assistente de vendas com IA voltado para apoiar vendedores do grupo Heineken
na introdução e crescimento da marca FYS de refrigerantes — especialmente em
padarias (menos de 1% de adesão nacional) e na ampliação em bares que já são
clientes de outros produtos Heineken.

O assistente levanta perguntas contextuais e entrega, de forma personalizada:
- Bullet points com argumentos de venda
- Script de conversa para abordar o dono do estabelecimento
- Sugestão de oferta comercial para fechamento

## 🎯 Problema que resolve

Vendedores enfrentam desafios de comunicação, argumentação e processo ao entrar
em mercados pouco explorados ou ao ampliar portfólio em mercados já estabelecidos.
O assistente resolve isso com um fluxo simples e adaptado ao contexto de cada
estabelecimento.

## 🤖 Como a IA ajuda

A IA identifica o perfil do estabelecimento através de perguntas direcionadas
ao vendedor. Com base nas respostas, gera um kit completo de abordagem adaptado
ao contexto — concorrentes presentes, tipo de cliente e histórico com a Heineken.

Fluxo:
1. Vendedor informa o tipo de estabelecimento (padaria ou bar)
2. IA faz perguntas específicas para cada caso
3. IA entrega argumentos, script e oferta personalizados

## 🚀 Como usar

1. Acesse o arquivo `prompt/sistema.md`
2. Cole o conteúdo como primeira mensagem em qualquer assistente de IA
   compatível (Claude, ChatGPT, Copilot)
3. Responda as perguntas do assistente como se fosse o vendedor
4. Receba o kit completo de abordagem

## 💡 Exemplos reais

Veja conversas reais testadas com o assistente na pasta `/exemplos`:
- `padaria-coca-fanta-h2oh.md` — padaria com concorrentes tradicionais
- `bar-cliente-heineken.md` — bar já parceiro Heineken
